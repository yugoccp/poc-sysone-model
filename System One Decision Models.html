2 · System 1 vs System 2

Kahneman's idea, applied to AI

System 1System 2
HumanFast, instinctSlow, careful
AIDecision modelReasoning LLM
OutputTyped value + probabilityText, code, plans
Best forRouting, gating, scoringWriting, analysis, planning

Not a replacement. Decision models judge, reasoning models think, software acts.

3 · Discriminative vs Generative

Pick an outcome, or build an answer

Discriminative

  • Choose between known outcomes
  • Probabilities sum to 1
  • Output format is fixed

Generative (autoregressive)

  • Writes one token at a time
  • Latency grows with output length
  • Format can break or drift

Jev works like a discriminative model, but trained at internet scale, so it works zero-shot on new questions. It answers all questions in one parallel pass.

4 · The Three Primitives

Choice, Score, Noul

Choice

Pick one option.

Ticket category: billing, technical, account

Score

Rate against a rubric.

Urgency from low to high

Noul

Yes or no.

Is the user asking for a refund?

One state, many questions, one round trip. Confidence thresholds live in your code: act, escalate, or fall back.

5 · Jev and Open Source Alternatives

Easy to copy the interface, hard to copy the accuracy

Jev (hosted)

  • Vendor claim: 40× to 200× faster than LLMs
  • Reported latency: 70 to 500 ms
  • Also via gateways like nexos.ai and ZenMux

Open source

  • Laya: base model to fine-tune
  • NanoJev: 0.6B, MIT license
  • SemIf: read option logits from your own model
  • NLI / GLiClass: older zero-shot classics

Independent benchmark: Jev 0.966 macro accuracy vs 0.704 for the best open model. Fine-tuning closes part of the gap.

6 · Trade-offs and Limitations

Know when not to use it

Where it wins

  • Routing and classification
  • Guard checks and gating
  • Fast judge for agent traces
  • Lower cost, no format errors

Limits

  • No generation, no explanation
  • Text input only
  • Hosted, proprietary, very new
  • Valid does not mean correct: build your own eval set

Rule: fixed options, frequent, latency matters → System One. Needs reasoning or writing → LLM.
