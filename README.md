 # poc-sysone-model

An experimental proof of concept for exploring System One Decision Model with Nimble and Ollama.

## Overview

This repository is to prototype ideas, test integrations, and document findings related to Nimble.

## Getting started

Downlaod and serve Nimble model with ollama:

```sh
ollama serve
ollama pull nimble
ollama run nimble
```

Clone the repository and inspect its contents:

```sh
git clone <repository-url>
cd poc-sysone-model
```

Run the code:

```sh
java SystemOnModelExample.java
```
